# Assets and licensing

Ashfall is open source, so every asset must carry a licence we can actually
ship. Record new art here **as it is added** — retrofitting attribution across
a finished asset pipeline is miserable, and an unlicensed sprite is a legal
problem rather than a tidiness one.

## Current assets

Everything in `apps/client/art/` is **placeholder art generated by
`tools/gen_placeholder_art.py`**, authored for this project and covered by the
repository's licence. Regenerate it with:

```bash
python3 tools/gen_placeholder_art.py
# then, so Godot picks up new files:
godot --headless --import --path apps/client
```

| File | Size | Purpose |
|---|---|---|
| `terrain.png` | 128x192 | Ground atlas: 4 variants x 6 tile types, one row per `TileType` |
| `tree_0/1/2.png` | 32x56..72 | Trees. One tile of footprint, two to three of height |
| `boulder.png` | 32x48 | Rock outcrop |
| `player.png` | 16x24 | Placeholder character |

## Replacing with real art

The tile layout is the contract, not the pixels: keep one row per `TileType` in
enum order and any atlas drops straight in. Props are anchored at the **feet**
(bottom centre), so taller sprites work without code changes.

## Choosing sources

Prefer **CC0** — no attribution chain and no downstream obligations.
[Kenney](https://kenney.nl) is the dependable CC0 source.

Avoid **CC-BY-SA** and **GPL** art (notably the LPC sets): the share-alike
terms are viral and will constrain how the rest of the project can be used.

Pick **one pack for base terrain**. Mixing packs is the most visible sign of a
project assembled from whatever was free, because palettes and outline styles
never quite agree.
